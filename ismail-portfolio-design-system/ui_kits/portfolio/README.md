# Portfolio website — UI kit

Click-through recreation of the source site (evelyn.framer.photos), rebranded to Ismail Kayadelen: homepage, about,
work index, case study and contact. Screens compose the published components only —
no local restyling. Navigation is faked in `index.html` with a `screen` state; the
menu overlay and hover states are real.

Screens: `Home.jsx` · `About.jsx` · `Work.jsx` · `WorkDetail.jsx` · `Contact.jsx`
Shared data (projects, experience, awards): `data.js`
