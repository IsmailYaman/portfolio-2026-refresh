Lucide line icon drawn inline (no network request), coloured by `color` (defaults to currentColor).

Available: arrow-up-right, arrow-right, arrow-down, menu, x, mail, phone, map-pin, external-link, plus, chevron-right, instagram.

```jsx
<Icon name="arrow-up-right" size={18} />
<Icon name="menu" size={22} color="var(--ev-paper)" />
```

Substitution: the source site has no icon library of its own — Lucide is the closest free match. Line only; never fill, never duotone, never emoji.
